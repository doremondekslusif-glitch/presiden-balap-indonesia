# 🇮🇩 Presiden Balap Indonesia

**Presiden Balap Indonesia** adalah game balap kart arcade 3D berbasis browser yang mengambil latar **Bali Circuit**, sebuah sirkuit fiktif dengan nuansa lingkungan Indonesia.

Game ini dikembangkan menggunakan **Three.js + WebGL** dan dirancang sebagai game arcade yang ringan, mudah dimainkan, dan dapat dijalankan langsung melalui browser.

> 🏎️ Pilih karakter → pilih sirkuit → mulai balapan → selesaikan 3 lap → lihat hasil balapan.

---

## 🎮 Fitur Game

Game saat ini memiliki beberapa sistem utama:

- 🏎️ Balapan kart 3D
- 🌴 Bali Circuit dengan lingkungan bertema Indonesia
- 🤖 AI racer
- 👤 Sistem karakter
- ⚡ Sistem acceleration dan speed
- 🚀 Boost
- 🛣️ Track boundary
- 💥 Collision dan perlambatan saat menabrak batas lintasan
- 🏁 Sistem lap
- ⏱️ Timer balapan
- 📍 Posisi pemain
- 🗺️ Mini-map
- 🎥 Kamera third-person mengikuti kart
- 🌫️ Fog dan environment lighting
- 🌳 Scenery berupa pohon, sawah, laut, gunung, dan bendera Indonesia
- 🚦 Countdown sebelum balapan
- 🏆 Ranking hasil balapan
- 🔄 Restart race
